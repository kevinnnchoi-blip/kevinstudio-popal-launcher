# 케빈스튜디오 · 포팔 서버

포켓몬과 함께, 우리의 모험이 시작되는 곳.

![케빈스튜디오 포팔 런처](launcher-preview.png)

**[Windows 설치 파일 다운로드](https://github.com/kevinnnchoi-blip/kevinstudio-popal-launcher/releases/download/v1.0.0/KevinStudio-Popal-Setup-1.0.0.exe)** · [릴리스 안내](https://github.com/kevinnnchoi-blip/kevinstudio-popal-launcher/releases/tag/v1.0.0)

1. 설치 파일을 실행합니다. 바탕화면에 **케빈스튜디오 포팔 서버** 바로가기가 생깁니다.
2. **Microsoft 로그인하고 시작**을 누르고, 표시된 인증 코드를 Microsoft 화면에 입력합니다. Minecraft Java Edition을 보유한 계정이 필요합니다.
3. 필요한 게임 파일을 자동으로 준비하고 **yangsook.com**에 접속합니다.

다음 실행부터는 저장된 계정으로 5초 후 자동 시작합니다. 런처 설정에서 메모리와 자동 시작 여부를 바꿀 수 있습니다.

## 포함 사항

- Minecraft 1.21.1 / Fabric 0.19.5 / Cobblemon 1.8.1
- r24 프로필의 모드 95개와 키 설정 84개
- ComplementaryReimagined r5.9.3와 세부 설정
- 리소스팩 및 활성화 순서, 서버 목록

모드팩은 설치기에 포함되어 있습니다. Java 21과 Minecraft 게임 파일은 첫 실행 시 공식 배포처에서 다운로드합니다. 설치 후 사용자가 바꾼 키·화면·셰이더 설정은 유지됩니다. 모드·리소스팩·셰이더 ZIP은 서버 배포본으로 확인·복구됩니다.

## 첫 검증 배포

설치 파일 214개의 원본 일치, 설정 보존, 손상 모드 복구, 새 환경에서 게임 의존 파일 설치, 실제 클라이언트 로드 및 서버 자동접속 시도까지 검증했습니다. **Microsoft 정품 로그인 완료 후 서버 입장 성공은 최종 확인이 남아 있어 검증용 사전 배포로 제공합니다.**

코드서명 인증서를 사용하지 않아 Windows에 게시자 미확인 경고가 표시될 수 있습니다. 릴리스의 SHA256.txt로 파일을 확인할 수 있습니다.

게임 데이터: `%APPDATA%\kevinstudio-popal`. 런처 제거 시에도 개인 설정과 게임 데이터는 남습니다. 기존 Modrinth 프로필은 수정하지 않습니다.

런처 제작: **케빈스튜디오**. 원본 게임·모드·리소스팩·셰이더의 권리는 각 제작자에게 있습니다. Minecraft 또는 Pokémon 공식 제품이 아닙니다.
