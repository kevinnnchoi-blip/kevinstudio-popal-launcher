## 설치와 업데이트

1. 실행 중인 포팔 게임과 공식 Minecraft 런처를 완전히 종료합니다.
2. 설치기를 실행합니다. **이미 설치했다면 먼저 삭제하지 말고 그대로 덮어 설치하세요.** 같은 앱·게임 폴더를 갱신하며 교체 대상 구파일은 정리됩니다.
3. 케빈스튜디오 런처에서 **공식 런처 열기**를 누릅니다.
4. 공식 Minecraft 런처에 Java Edition을 보유한 Microsoft 계정으로 로그인합니다.
5. **케빈스튜디오 포팔서버 → 플레이**를 누르면 yangsook.com에 자동접속을 시도합니다.

첫 실행에는 공식 런처가 게임·Java 파일을 내려받습니다. 공식 런처의 **플레이는 직접 눌러야 합니다.**

## 포함된 팩과 설정

- Minecraft 1.21.1 / Fabric 0.19.5 / Cobblemon 1.8.1 / **r32 모드 98개**
- Pokémon 한글팩 r27과 Sophisticated 한글팩 r32, 활성화 순서 포함
- 기존 ComplementaryReimagined r5.9.3 셰이더와 세부 설정
- 첫 설치 기본값: **음악 끔, GUI 크기 3, 기존 키 설정 84개 유지**. 새 모드의 키 기본값만 추가됩니다.
- 업데이트 시 사용자가 바꾼 키·음량·GUI·셰이더 설정을 보존합니다. 서버용 리소스팩 선택은 새 구성으로 갱신하고 개인 추가 리소스팩은 유지합니다.

## 제거

Windows 설정의 설치된 앱 또는 제어판에서 **케빈스튜디오 포팔 서버**를 제거하세요. 먼저 게임과 공식 Minecraft 런처를 완전히 종료해야 합니다.

제거하면 이 설치기의 앱, 전용 게임 파일·개인 설정·캐시·백업, 바로가기와 공식 런처의 전용 프로필·버전이 삭제됩니다. **원본 Modrinth 팩, Microsoft 계정, 다른 Minecraft 설치 프로필과 공용 게임 파일은 유지됩니다.** 게임 폴더에 따로 보관한 월드·스크린샷이 필요하면 제거 전에 복사해 두세요.
